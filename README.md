# supermarkets-performance-dashboard

This repository contains an interactive Power BI analytics dashboard developed to analyze large-scale supermarket sales data. The project transforms raw transaction records into actionable business insights covering revenue, product category performance, customer buying behavior, and branch sales distribution.

Key Insights & Visualizations
The Power BI report (`supermarket_large_dataset.pbix`) breaks down key business metrics across three main analytical areas:

1. Executive Summary & Sales Overview
Key Performance Indicators (KPIs): Total Revenue, Net Profit, Average Order Value (AOV), and Total Units Sold.
Time-series analysis of sales across months/quarters to identify peak shopping periods.

2. Product Category & Inventory Performance
Top & Bottom Performers: Revenue breakdown across food, household, electronics, and apparel categories.
Identification of high-volume vs. high-margin product categories.

3. Customer & Regional Analysis
Branch Comparison: Comparative performance analysis across store locations.
Sales breakdown by customer type (Member vs. Normal) and payment method preference (E-wallet, Credit Card, Cash).

Tools & Technologies
Microsoft Power BI Desktop, Power Query (ETL pipeline, data cleaning, structural transformation), Custom measures for dynamic time-intelligence (YTD, MoM growth) and aggregation metrics.
